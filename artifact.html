VS Code · GCC · Otomatik kurulum

Birinci sınıf için eksiksiz C geliştirme ortamı.

CForge, VS Code'u, C derleyicisini ve ders için gereken yapılandırmayı tek işlemde kurar; örnek projeyi oluşturur ve sonucu derleyip çalıştırarak doğrular. Yönetici yetkisi gerektirmez.

İndir

Kurulum sonunda VS Code, ilkprojem.c açık olarak başlar; F5 derler ve çalıştırır.

cforge — install

Örnek kurulum çıktısı: VS Code kuruluyor, derleyici kuruluyor, eklentiler kuruluyor, proje hazırlanıyor, doğrulanıyor — ardından «Merhaba Dunya! Ben bilgisayar muhendisiyim.» yazdırılıyor ve kurulum tamamlanıyor.
